# Z-Society

**An independent cybersecurity CTF team focused on learning, collaboration, and ethical problem-solving.**

Z-Society brings together curious minds who enjoy exploring how systems work, understanding how they fail, and developing practical cybersecurity skills through hands-on challenges. We learn from every flag, every mistake, and every competition.

---

## About

Our team uses Capture The Flag (CTF) competitions as a practical way to strengthen technical knowledge, sharpen problem-solving skills, and learn collaboratively.

Our current areas of interest include:

- **Web Security** — exploring common web vulnerabilities and exploitation techniques.
- **Digital Forensics** — examining digital evidence and investigating artifacts.
- **Cryptography** — understanding cryptographic concepts and solving cipher-based challenges.
- **Reverse Engineering** — analysing programs and understanding their behaviour.
- **Networking** — investigating protocols, traffic, and network-based challenges.
- **Steganography** — identifying and analysing information concealed in digital media.

These are learning areas, not a claim that every member specialises in each discipline.

## Our Approach

- **Learn together:** Share knowledge, techniques, and useful writeups.
- **Compete responsibly:** Practise ethical hacking in authorised environments.
- **Improve continuously:** Treat challenges, including unsuccessful attempts, as opportunities to learn.
- **Build practical skills:** Focus on understanding concepts rather than simply collecting flags.

## Website

The repository contains the source for the Z-Society team website, featuring team information, member profiles, and competition milestones.

### Run locally

1. Clone this repository:
   ```bash
   git clone https://github.com/Jixsaw79/Z-Society.git
   ```
2. Open the project directory:
   ```bash
   cd Z-Society
   ```
3. Open `index.html` in a web browser.

No build step or package installation is required for the current static website.
